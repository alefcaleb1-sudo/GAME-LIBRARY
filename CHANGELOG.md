# CHANGELOG — Game Library

Este arquivo registra as alterações realizadas durante o desenvolvimento do projeto Game Library.

## [0.1.0] — 30/10/2026

### Adicionado
- Estrutura inicial do site Game Library.
- Página inicial com 15 jogos apresentados em cards.
- Campo de pesquisa de jogos.
- Página de detalhes reutilizável.
- Seções de descrição, história, itens principais, mobs, personagens, curiosidades e Easter Eggs.
- Informações iniciais do Minecraft.
- Botão para retornar à página inicial.

### Alterado
- Integração entre HTML e JavaScript para exibição dinâmica das informações.
- Organização da navegação entre a página inicial e a página de detalhes.

### Corrigido
- Ajustes na navegação entre as telas.
- Correção na identificação e exibição do título e da descrição do jogo selecionado.

### Removido
- Nenhum recurso removido nesta versão.

---

**Observação:** Esta versão representa a etapa inicial do projeto. O desenvolvimento continua, com previsão de novas funcionalidades e inclusão das informações dos demais jogos.
